# وزارة الصحة: قرار وزاري رقم ٨٢ / ٢٠٠٠ بتحديد رسوم إصدار وتجديد التراخيص للمواد المخدرة والمؤثرات العقلية

استنادا إلى قانون مكافحة المخدرات والمؤثرات العقلية الصادرة بالمرسوم السلطاني رقم ١٧ / ٩٩،

وإلى القانون المالي الصادر بالمرسوم السلطاني رقم ٤٧ / ٩٨ وتعديلاته،

وإلى كتاب وزارة المالية رقم مالية / ت – (٤٧) / م.ت.د / ٦ / ٣ / ٢٥ / المؤرخ ١١ / ١٠ / ١٤٢١هـ الموفق ٦ / ١ / ٢٠٠١م،

وبناء على ما تقتضيه المصلحة العامة.

تقرر

## مادة (١)

تحدد رسوم إصدار وتجديد التراخيص المشار إليها في المادة (١٨) من قانون مكافحة المخدرات والمؤثرات العقلية على النحو الآتي:

| نوع التراخيص | قيمة الرسم بالريال العماني |
| --- | --- |
| زراعة نباتات مخدرة. | ٥٠ |
| صنع أو إنتاج أدوية يدخل في تركيبها مواد مخدرة أو مؤثرات عقلية. | ٥٠ |
| استيراد مواد مخدرة أو مؤثرات عقلية. | ١٠ |
| تصدير مواد مخدرة أو مؤثرات عقليه. | ١٠ |
| نقل مواد مخدرة أو مؤثرات عقلية. | ٢ |
| التعامل في مواد مخدرة أو مؤثرات عقلية. | ١٠ |
| الاتجار في مواد مخدرة أو مؤثرات عقلية | ١٠ |

## مادة (٢)

ينشر هذا القرار في الجريدة الرسمية، ويعمل به اعتبارا من تاريخ نشره.

**صدر في: ٢٣ من رجب ١٤٢١هـ**

**الموافق: ٢١ من أكتوبر ٢٠٠٠م**

**الدكتور / علي بن محمد بن موسى**

**وزير الصحة**

نشر في عدد الجريدة الرسمية رقم (٦٨٨) الصادر في ٣ / ٢ / ٢٠٠١م
