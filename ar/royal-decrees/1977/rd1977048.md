# مرسوم سلطاني رقم ٤٨ / ٧٧ بتعديل قانون الحركة الكشفية في سلطنة عمان

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم رقم ١٢ / ٧٦ القاضي بإحداث وزارة لشؤون الشباب،

وعلى المرسوم رقم ٢١ / ٧٦ في ضبط اختصاصات تلك الوزارة،

وعلى المرسوم رقم ١٠ / ٧٥ بإصدار قانون تنظيم الحركة الكشفية في سلطنة عمان وتعديلاته،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## المادة ١

يلغى نص المادة السادسة من الباب الثاني من قانون تنظيم الحركة الكشفية في سلطنة عمان المشار إليه ويعوض بالنص التالي:

## المادة ٦

يدير الهيئة القومية للكشافة والمرشدات مجلس إدارة يتكون من:

| رئيس الهيئة ويصدر بتعيينه قرار سلطاني |  |
| --- | --- |
| وزير التربية والتعليم | نائبا للرئيس |
| المديرة العامة لتعليم البنات بوزارة التربية والتعليم | عضوا |
| المدير العام للإذاعة والتلفزيون بوزارة الإعلام والثقافة | عضوا |
| المدير العام للشؤون الاجتماعية بوزارة الشؤون الاجتماعية والعمل | عضوا |
| مدير شؤون الشباب بوزارة شؤون الشباب | عضوا |
| مدير الميزانية بوزارة المالية | عضوا |
| المشرفون التعليميون بمناطق السلطنة بوزارة التربية والتعليم | أعضاء |
| سبعة من المهتمات بحركة المرشدات بوزارة التربية والتعليم وجمعية المرأة العمانية | عضوات |
| مفوض عام الكشافة بالسلطنة | عضوا |

ويجرون فيما بينهم في أول اجتماع لهم، تشكيل جمعية للكشافة وجمعية للمرشدات مع تحديد اختصاصات ومسؤوليات كل من الجمعيتين ثم يجري انتخاب الرئيس وأمين السر وأمين الصندوق ومشرف التدريب لكل منهما.
