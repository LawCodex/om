# مرسوم سلطاني رقم ٣١ / ٧٩ بإعادة تشكيل مجلس المناقصات

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٥٢ / ٧٥ الخاص بنظام المناقصات،

وعلى المرسوم رقم ٣٧ / ٧٥ بشأن مجلس المناقصات وتعديلاته،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## المادة ١

يعاد تشكيل مجلس المناقصات من الأعضاء المذكورين أدناه:

| ١- السيد ثويني بن شهاب | رئيسا |
| --- | --- |
| ٢- وزير المواصلات | عضوا |
| ٣- وزير التربية والتعليم | عضوا |
| ٤- وزير النفط والمعادن | عضوا |
| ٥- وزير الشؤون الاجتماعية والعمل | عضوا |
| ٦- وزير الكهرباء والمياه | عضوا |
| ٧- وكيل وزارة شؤون الديوان السلطاني | عضوا |
| ٨- وكيل الشؤون المالية | عضوا |
| ٩- وكيل مجلس التنمية | عضوا |
| ١٠- مندوب عن الوزارة المعنية | عضوا |
