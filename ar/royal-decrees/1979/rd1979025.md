# مرسوم سلطاني رقم ٢٥ / ٧٩ بمنح الجنسية العمانية لبعض الأفراد في قوات السلطان المسلحة

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على قانون الجنسية العمانية رقم (١) لسنة ١٩٧٢.

رسمنا بما هو آت

## المادة ١

تمنح الجنسية العمانية لأفراد قوات السلطان المسلحة المبينة أسماؤهم أدناه:

| رقم | الاسم | الرقم العسكري |
| --- | --- | --- |
| ١ | ملا بخش تاج البلوشي | ٦٣٧٩ |
| ٢ | رحيم داد علي شار شمبيه | ٥٧٩٨ |
| ٣ | حاجي جان محمد البلوشي | ٠٣٥٧ |
| ٤ | يوسف محمد يوسف البلوشي | ٥١٤٩ |
| ٥ | شاه مراد عاشور البلوشي | ٦٠٥٨ |
| ٦ | كريم جان جان محمد محمد خان البلوشي | ٤٨٧٦ |
| ٧ | نصير حاصل جان ابوبكر البلوشي | ٨٥١١ |
| ٨ | كريم خان حاجي داد رحمة البلوشي | ٥٩٩١ |
| ٩ | ولي محمد حاجي مراد محمد البلوشي | ٦٤٩٢ |
| ١٠ | محمد بخش نور محمد البلوشي | ٦٤٧٣ |
| ١١ | عبدالباقي الشكران جمعه البلوشي | ٠٥٧٢ |
| ١٢ | خدادات ميار حسن البلوشي | ٣٩٢٢ |
| ١٣ | محمد حسين علي مراد البلوشي | ٣٧٩٣ |
| ١٤ | فتح محمد لشكران جمعه البلوشي | ٥٩٨١ |
| ١٥ | يوسف عبدالرحيم رستم البلوشي | ٨٤٨٩ |
