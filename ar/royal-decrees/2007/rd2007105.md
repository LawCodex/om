# مرسوم سلطاني رقم ١٠٥ / ٢٠٠٧ بإعادة تشكيل مجلس المناقصات

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على النظام الأساسي للدولة الصادر بالمرسوم السلطاني رقم ١٠١ / ٩٦،

وعلى قانون ونظام المناقصات الحكومية الصادرين بالمرسوم السلطاني رقم ٨٦ / ٨٤،

وعلى المرسوم السلطاني رقم ٩٤ / ٢٠٠٧ بإجراء تعديل وزاري،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## المادة الأولى

يعاد تشكيل مجلس المناقصات برئاسة وزير النقل والاتصالات وعضوية كل من:

| – وزير البلديات الإقليمية وموارد المياه | نائبا للرئيس |
| --- | --- |
| – وزير القوى العاملة. |  |
| – وزير الخدمة المدنية. |  |
| – أمين عام وزارة المالية. |  |
| – وزير الإسكان. |  |
| – وكيل وزارة الاقتصاد الوطني لشؤون التنمية. |  |
| – وكيل وزارة التجارة والصناعة للتجارة والصناعة. |  |
| – أمين عام اللجنة العليا لتخطيط المدن. |  |
| – أمين عام مجلس المناقصات. |  |

## المادة الثانية

يلغى كل ما يخالف هذا المرسوم.
