# مرسوم سلطاني رقم ٥٦ / ٧٨ بإعادة تشكيل مجلس المناقصات

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم رقم ٥٢ / ٧٥ الخاص بنظام المناقصات،

وعلى المرسوم رقم ٣٧ / ٧٥ بشأن تشكيل مجلس المناقصات والمرسوم رقم ٥٣ / ٧٧ بإضافة أعضاء لمجلس المناقصات.

رسمنا بما هو آت

## المادة ١

يعاد تشكيل مجلس المناقصات من الأعضاء المذكورين أدناه:

| السيد ثويني بن شهاب | رئيسا |
| --- | --- |
| وزير المواصلات | عضوا |
| وزير التربية والتعليم | عضوا |
| وزير الزراعة والأسماك والنفط والمعادن | عضوا |
| وزير الشؤون الاجتماعية والعمل | عضوا |
| وزير الكهرباء والمياه | عضوا |
| وكيل وزارة شؤون الديوان السلطاني | عضوا |
| وكيل الشؤون المالية | عضوا |
| وكيل مجلس التنمية | عضوا |
| ممثل الوزارة المعنية | عضوا |

## المادة ٢

ينشر هذا المرسوم في الجريدة الرسمية ويعمل به من تاريخ نشره.

**صدر في: ٢٢ شوال ١٣٩٨هـ**

**الموافق: ٢٥ سبتمبر ١٩٧٨م**

**قابوس بن سعيد**

**سلطان عمان**

نشر هذا المرسوم في عدد الجريدة الرسمية رقم (١٥٦) الصادر في ١ / ١٠ / ١٩٧٨م.
