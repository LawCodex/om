# مرسوم سلطاني رقم ٤١ / ٩٢ بتعديل المرسوم السلطاني رقم ٦٤ / ٨٣ بتأسيس المعهد المصرفي العماني

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى القانون المصرفي رقم (٧) لسنة ١٩٧٤م،

وعلى المرسوم السلطاني رقم ٦٤ / ٨٣ بتأسيس المعهد المصرفي العماني،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة (١)

يستبدل بنص المادة ٤ من المرسوم السلطاني رقم ٦٤ / ٨٣ النص الآتي:

يشكل مجلس إدارة المعهد المصرفي على النحو التالي:

| – ممثلان عن البنك المركزي العماني يعينهما الرئيس التنفيذي للبنك المركزي. |  | يكون أحدهما رئيسا للمجلس والآخر نائبا للرئيس |
| --- | --- | --- |
| – ممثل عن وزارة التربية والتعليم يعينه الوزير. |  | عضوا |
| – ممثل عن هيئة التدريب المهني يعينه رئيس الهيئة. |  | عضوا |
| – أربعة ممثلين عن المصارف تعينهم المصارف المرخصة. |  | أعضاء |
| – مدير المعهد أو نائبه. |  | عضوا ومقررا |

## مادة (٢)

على جميع الجهات المعنية تنفيذ أحكام هذا المرسوم كل فيما يخصه.

## مادة (٣)

ينشر هذا المرسوم في الجريدة الرسمية ويعمل به اعتبارا من تاريخ نشره.

**صدر في: ١٥ ذو الحجة سنة ١٤١٢هـ**

**الموافق: ١٦ يونيو سنة ١٩٩٢م**

**قابوس بن سعيد**

**سلطان عمان**
