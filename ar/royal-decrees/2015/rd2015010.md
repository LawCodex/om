# مرسوم سلطاني رقم ١٠ / ٢٠١٥ بإعادة تشكيل مجلس المناقصات

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على النظام الأساسي للدولة الصادر بالمرسوم السلطاني رقم ١٠١ / ٩٦،

وعلى قانون المناقصات الصادر بالمرسوم السلطاني رقم ٣٦ / ٢٠٠٨،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## المادة الأولى

يعاد تشكيل مجلس المناقصات برئاسة رئيس مجلس المناقصات وعضوية كل من:

| – أمين عام المجلس الأعلى للتخطيط | نائبا للرئيس |
| --- | --- |
| – وزير الإسكان |  |
| – وزير الخدمة المدنية |  |
| – وزير البيئة والشؤون المناخية |  |
| – وكيل وزارة الداخلية |  |
| – وكيل وزارة المالية |  |
| – وكيل وزارة التجارة والصناعة للتجارة والصناعة |  |
| – وكيل وزارة الشؤون القانونية |  |
| – أمين عام مجلس المناقصات |  |

ويجوز للمجلس الاستعانة بأي من الخبراء والمختصين وفقا لضرورة ومقتضيات العمل.

## المادة الثانية

يلغى كل ما يخالف هذا المرسوم.
