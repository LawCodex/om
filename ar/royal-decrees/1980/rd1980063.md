# مرسوم سلطاني رقم ٦٣ / ٨٠ بإعادة تشكيل مجلس التربية والتعليم والتدريب المهني

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٤٣ / ٧٧ بإنشاء مجلس للتربية والتعليم والتدريب المهني،

وعلى المرسوم السلطاني رقم ٤ / ٧٨ بإعادة تشكيل المجلس،

وعلى المرسوم السلطاني رقم ٢٨ / ٧٩ بإجراء تعديلات في تشكيل مجلس الوزراء،

ونظرا لما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة ١

يعدل تشكيل مجلس التربية والتعليم والتدريب المهني المنشأ بمقتضى المرسوم رقم ٤٣ / ٧٧ المشار إليه على النحو التالي تحت رئاستنا:

| وزير التراث القومي والثقافة | نائبا للرئيس |
| --- | --- |
| وزير التربية والتعليم | عضوا |
| وزير الشؤون الاجتماعية والعمل | عضوا |
| وزير التجارة والصناعة | عضوا |
| وزير العدل | عضوا |
| وزير النفط والمعادن | عضوا |
| وزير الأوقاف والشؤون الإسلامية | عضوا |
| وزير الزراعة والأسماك | عضوا |
| وزير الإعلام وشؤون الشباب | عضوا |
| وكيل المديرية العاملة للمالية | عضوا |
| مندوب عن وزارة التربية والتعليم أو وزارة الشؤون الاجتماعية والعمل | أمينا عاما للمجلس |
