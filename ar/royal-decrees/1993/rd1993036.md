# مرسوم سلطاني رقم ٣٦ / ٩٣ بتعديل المرسوم السلطاني رقم ٩٥ / ٨٨ بنظام اللجنة الوطنية العمانية للتربية والثقافة والعلوم

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٩٥ / ٨٨ بنظام اللجنة الوطنية العمانية للتربية والثقافة والعلوم،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة (١)

يستبدل بنص المادة (٢) من نظام اللجنة الوطنية العمانية للتربية والثقافة والعلوم المشار إليه النص الآتي:

تشكل اللجنة على النحو التالي:

| أولا – | وزير التربية والتعليم | رئيسا |
| --- | --- | --- |
| ثانيا – | وكيل الوزارة لشؤون البعثات والعلاقات الخارجية | نائبا للرئيس |
| ثالثا – | ممثل بدرجة مدير عام عن كل من وزارات: |  |
|  | – التربية والتعليم | عضوا |
|  | – الشؤون الاجتماعية والعمل | عضوا |
|  | – الخارجية | عضوا |
|  | – الزراعة والثروة السمكية | عضوا |
|  | – البلديات الإقليمية والبيئة | عضوا |
|  | – موارد المياه | عضوا |
|  | – الإعلام | عضوا |
|  | – التراث القومي والثقافة | عضوا |
| رابعا – | ممثل عن جامعة السلطان قابوس | عضوا |
| خامسا – | ممثل عن مجلس التنمية | عضوا |
| سادسا – | ممثل عن الهيئة العامة لأنشطة الشباب الرياضية والثقافية | عضوا |
| سابعا – | ثلاثة يعينهم رئيس اللجنة من بين الأشخاص المهتمين بشؤون التربية والثقافة والعلوم. <br><br>وتكون عضويتهم لمدة ثلاث سنوات قابلة للتجديد | أعضاء |
| ثامنا – | سكرتير عام اللجنة | عضوا ومقررا |
