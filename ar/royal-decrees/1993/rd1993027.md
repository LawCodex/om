# مرسوم سلطاني رقم ٢٧ / ٩٣ بإعادة تشكيل اللجنة الوطنية للتعداد

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٨٧ / ٨٨ بإصدار القانون الإحصائي،

وعلى المرسوم السلطاني رقم ٥٠ / ٩١ بإجراء التعداد السكاني الشامل،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة (١)

يعاد تشكيل اللجنة الوطنية للتعداد على النحو التالي:

| – الأمين العام لمجلس التنمية | رئيسا |
| --- | --- |
| – الوكيل لشؤون التخطيطي بالأمانة العامة لمجلس التنمية | نائبا للرئيس |
| – وكيل وزارة التربية والتعليم لشؤون التعليم العام | عضوا |
| – وكيل وزارة الإعلام للشؤون الإعلامية | عضوا |
| – وكيل وزارة الإسكان | عضوا |
| – وكيل وزارة التجارة والصناعة للتجارة | عضوا |
| – وكيل وزارة الداخلية | عضوا |
| – وكيل وزارة البلديات الإقليمية والبيئة لشؤون البلديات | عضوا |
| – وكيل وزارة الصحة لشؤون التخطيط | عضوا |
| – وكيل وزارة الشؤون الاجتماعية والعمل للشؤون الاجتماعية | عضوا |
| – نائب محافظ ظفار | عضوا |
| – نائب محافظ مسقط | عضوا |
| – رئيس بلدية مسقط | عضوا |
| – مساعد المفتش العام للشرطة والجمارك لشؤون العمليات والتدريب | عضوا |
| – مساعد رئيس الأركان للشؤون الإدارية بوزارة الدفاع | عضوا |

## مادة (٢)

ينشر هذا المرسوم في الجريدة الرسمية ويعمل به اعتبارا من تاريخ صدوره.
