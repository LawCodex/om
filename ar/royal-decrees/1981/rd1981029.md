# مرسوم سلطاني رقم ٢٩ / ٨١ بإعادة تشكيل مجلس التنمية وتعديل اختصاصاته

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٤١ / ٧٤ بإنشاء وتشكيل مجلس التنمية وتعديلاته،

وعلى المرسم السلطاني رقم ٩ / ٧٥ بإصدار قانون التنمية الاقتصادية لعام ١٩٧٥ رقم ١ / ٧٥،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة ١

يعاد تشكيل مجلس التنمية برئاستنا على النحو التالي:

| وزير الدولة للشؤون الخارجية | نائبا للرئيس |
| --- | --- |
| وزير التراث القومي والثقافة | عضوا |
| وزير النفط والمعادن | عضوا |
| وزير التجارة والصناعة | عضوا |
| وزير الكهرباء والمياه | عضوا |
| وزير الشؤون الاجتماعية والعمل | عضوا |
| وزير الزراعة والأسماك | عضوا |
| وزير المواصلات | عضوا |
| وزير شؤون الأراضي والبلديات | عضوا |
| وكيل شؤون المالية | عضوا |
| أمين عام مجلس التنمية | عضوا |

## مادة ٢

على مجلس التنمية بالإضافة إلى اختصاصاته المحددة في الملحق (أ) لقانون تنظيم الجهاز الإداري للدولة المشار إليه أن يقدم تقارير ربع سنوية عن ما تم إنجازه من مراحل خطة التنمية خلال كل عام.

## مادة ٣

يلغى المرسوم السلطاني رقم ٤١ / ٧٤ المشار إليه، كما يلغى كل ما يتعارض مع أحكام هذا المرسوم أو يخالفها.

## مادة ٤

ينشر هذا المرسوم في الجريدة الرسمية ويعمل به من تاريخ صدوره.
