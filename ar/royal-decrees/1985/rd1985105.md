# مرسوم سلطاني رقم ١٠٥ / ٨٥ بتعديل اسم مجلس حماية البيئة ومكافحة التلوث وإعادة تشكيله

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٤٥ / ٧٥ بشأن تشكيل مجلس مصادر المياه وتعديلاته،

وعلى المرسوم السلطاني رقم ٧٦ / ٧٧ بإصدار قانون تنمية موارد المياه،

وعلى المرسوم السلطاني رقم ٦٩ / ٧٩ بإنشاء مجلس حماية البيئة ومكافحة التلوث وتعديلاته،

وعلى المرسوم السلطاني رقم ١٠٤ / ٨٥ بتعديل اسم وزارة البيئة واختصاصها،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة ١

يعدل اسم مجلس حماية البيئة ومكافحة التلوث ليصبح “مجلس حماية البيئة وموارد المياه”.

## مادة ٢

يعاد تشكيل المجلس برئاستنا على النحو الآتي:

| – وزير البيئة وموارد المياه | نائبا للرئيس |
| --- | --- |
| – وزير المواصلات | نائبا مساعدا |
| – وزير الزراعة والأسماك | عضوا |
| – وزير الكهرباء والمياه | عضوا |
| – وزير الداخلية | عضوا |
| – وزير الصحة | عضوا |
| – وزير الإسكان | عضوا |
| – وزير التجارة والصناعة | عضوا |
| – وزير الدولة ووالي ظفار | عضوا |
| – وزير النفط والمعادن | عضوا |
| – وزير شؤون البلديات الإقليمية | عضوا |
| – رئيس ديوان شؤون البلاط السلطاني | عضوا |
| – أمين عام المجلس | عضوا |

## مادة ٣

يتولى المجلس كافة الاختصاصات التي كانت مقررة أصلا لكل من مجلس حماية البيئة ومكافحة التلوث ومجلس موارد المياه إلى أن يعاد تحديد تلك الاختصاصات بمرسوم سلطاني خاص.
