# مرسوم سلطاني رقم ٥٨ / ٨٥ بإعادة تشكيل مجلس حماية البيئة ومكافحة التلوث

نحن قابوس بن سعيد سلطان عمان

بعد الاطلاع على المرسوم السلطاني رقم ٢٦ / ٧٥ بإصدار قانون تنظيم الجهاز الإداري للدولة وتعديلاته،

وعلى المرسوم السلطاني رقم ٦٨ / ٧٩ بإنشاء مجلس حماية البيئة ومكافحة التلوث وتعديلاته،

وعلى المرسوم السلطاني رقم ٥٢ / ٨٥ بتعيين أمين عام لمجلس حماية البيئة ومكافحة التلوث،

وبناء على ما تقتضيه المصلحة العامة.

رسمنا بما هو آت

## مادة ١

يعاد تشكيل مجلس حماية البيئة ومكافحة التلوث برئاستنا على النحو التالي:

| وزير المواصلات | نائبا للرئيس |
| --- | --- |
| وزير البيئة | نائبا مساعدا للرئيس |
| وزير الزراعة والأسماك | عضوا |
| وزير الكهرباء والمياه | عضوا |
| وزير الصحة | عضوا |
| وزير الإسكان | عضوا |
| وزير الداخلية | عضوا |
| وزير التجارة والصناعة | عضوا |
| وزير الدولة ووالي ظفار | عضوا |
| وزير النفط والمعادن | عضوا |
| وزير شؤون البلديات الإقليمية | عضوا |
| رئيس ديوان شؤون البلاط السلطاني | عضوا |
| أمين عام مجلس حماية البيئة ومكافحة التلوث | عضوا |

## مادة ٢

ينشر هذا المرسوم في الجريدة الرسمية ويعمل به اعتبارا من تاريخ صدوره.
